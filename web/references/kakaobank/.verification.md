- No focus token. `#007bff` matches a common framework default by value only; the site's stylesheet was not read, so the ring is recorded per component as an authored outline and kept out of `tokens.colors`.
- No selected fill for the service pill: the selected pill's black fill is painted by another element that was not identified.

- `brand-spec-row` is not interactive and was not probed.

### Corrections

- `top-navigation`: pressed `#141414` and focus `#131313`, claimed from the 2026-07-12 capture, were early frames of the 0.4s transition; the July hover sample read `#141414` too. Each lies on the grey line from `#000000` to the settled `#444444` (one scale factor, about 0.29, rounds all three channels to 20; about 0.28 rounds them to 19), and the live frame sample passes `#141414` at 363 ms. Settled pressed is `#444444`; focus changes only the outline.
- `service-tab`: typed `tab`, but the element is an accordion `button` with `aria-expanded` and no `role=tab`. Retyped `button`; the name is kept so existing claims stay attached. Its font was the button's own 16px/400; the visible label is a 20px/700 heading.
- `resource-download`: its font was the anchor's own 16px/400; the visible label span is 15px/600.
- `black-action` and `resource-download` said no hover or pressed value was promoted while declaring `hover: #444444`. That value is a background change, and pressed equals it.
