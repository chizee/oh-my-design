## Colour scheme

- **Collector setting:** the collector's `browser.newContext` sets no `colorScheme`. The capture machine's macOS appearance was Dark.
- **Canvas:** the served HTML sets the page background outside any colour-scheme query: `<style data-framer-html-style>html body { background: rgb(17, 17, 17); }</style>`, plus inline `background-color:rgb(17, 17, 17)` on the Desktop and Phone root frames.
- **Text tokens:** the HTML's `@media (prefers-color-scheme:dark)` block re-declares six colour tokens. The two checked against their inline fallbacks carry the same values under both schemes:
  - token `428b8bf6`: `#fafafa`, fallback `rgb(250, 250, 250)` ×149
  - token `18f38c56`: `#1a2128`, fallback `rgb(26, 33, 40)` ×17
- **Conclusion:** the dark render is the site's design, not an OS-scheme artefact.
